# rpoCdb website — design preview

A sample homepage for rpocdb.github.io, built to review the look and feel
(color scheme, typography, layout, content sections) before merging anything
into the live site. Open `index.html` directly, or enable GitHub Pages on
this repo to view it live.

Sections: hero, database stats, why rpoC, downloads (with a Zenodo callout),
CUSTARD pipeline, primers & library prep, publications, footer.

Private — for internal review only.
